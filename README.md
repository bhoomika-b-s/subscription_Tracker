Project: Subscription Tracker

Helps to track the number of subscritions the user has.

Features:
Shows the total amount spent on each subscription.

Suggests whether the subscription should be renewed or not based on its usage.

Shows the existing subscriptions.

Built using: 

1. Next.js
2. Tailwind CSS

How to run:
1. git clone https://github.com/bhoomika-b-s/subscription_Tracker.git
2. cd subscription-tracker
3. npm install
4. npm run dev
